## THE BUG (verified by coordinator, real output)

`near "(": syntax error at offset 80: SQLITE_ERROR`.
Cause: `migrations/0004_multiuser_and_mfa.sql` + `0005_mfa_tables.sql` are written
in POSTGRESQL dialect, not SQLite/D1: `UUID PRIMARY KEY DEFAULT gen_random_uuid()`,
`TEXT NULLABLE`, `SELECT setval(...)`, `'...'::uuid` casts,
`EXTRACT(EPOCH FROM NOW())`, `GENERATED BY DEFAULT AS IDENTITY`.

the old `users` table (from 0002/0003) already exists — the new schema (id,
role, display_name, status) never materializes. A real migration is required.
